# Projects

A collection of ham radio and RF-related projects I'm working on.

## RF & Signals

### SIGINT Research
Signals intelligence and RF research — exploring the electromagnetic spectrum, signal identification, and analysis techniques.

### Trash Dump to RF Dump
A BSides talk project about reviving dead consumer hardware as RF security tools. Turning e-waste into useful SDR and RF analysis platforms.

### OUI Spy Too
MAC/OUI-based surveillance device detection. Identifying wireless surveillance equipment by analyzing manufacturer identifiers in the RF environment.

## Data & Tools

### FCC ULS Database (KF7ATW)
Working with FCC Universal Licensing System data exports for amateur radio license lookups and analysis.

### ULS Lookup 2025
Updated FCC ULS database export tools for 2025 data.

## Hardware

### Hotspot Swarm
Distributed IMSI catcher detection fleet — a network of sensors for detecting rogue cellular base stations.

### Orbic RC400L Research
Security research on the Orbic RC400L cellular device platform.

### Cynthion USB Toolkit
USB security research using the Cynthion platform for protocol analysis and testing.
